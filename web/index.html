Despliega tu FacturaBot ☁️

Este servicio recibe los mensajes de Telegram vía POST /webhook. Usa uno de los botones para desplegarlo con un clic (los valores del formulario ya están preconfigurados desde render.yaml / vercel.json):

Deploy to Render Deploy to Vercel
  1. Haz clic en el botón y conecta tu cuenta (Render o Vercel).
  2. En las variables de entorno pega tu BOT_TOKEN (nuevo, revocado el anterior), ALLOWED_USER_IDS y WEBHOOK_SECRET.
  3. Tras el despliegue, registra la URL pública ante Telegram: python -m facturabot.webhook (usa RENDER_EXTERNAL_URL / VERCEL_URL automáticamente).
  4. ⚠️ En Vercel la BD vive en /tmp (se pierde al reiniciar): ideal para probar. Para datos permanentes usa Render + Disk o Postgres.
